Descenso de Gradiente

[cite_start][cite: 71] Método iterativo para encontrar el mínimo local de una función diferenciable moviéndose en dirección opuesta a su gradiente.

🏔️ ¿Cómo funciona? (Teoría Simplificada)

La Analogía de la Montaña

Imagina que estás en la cima de una montaña en medio de una noche con niebla. Tu objetivo es llegar al punto más bajo (el valle), pero no puedes ver el camino completo.

¿Qué haces? Sientes la inclinación del suelo bajo tus pies (el gradiente) y das un paso en la dirección donde el terreno desciende más pronunciadamente. Repites esto paso a paso hasta llegar al fondo.

La Fórmula Maestra

xn+1 = xn - η · ∇F(xn)
  • xn : Tu posición actual.
  • ∇F(x) : El Gradiente (dirección de subida máxima). Restamos para ir en bajada.
    • [cite_start]
  • η (Eta) : [cite: 76] Tasa de aprendizaje (Learning Rate). Define qué tan grandes son tus pasos.

# Implementación del Descenso de Gradiente en R

gradiente_descendente <- function(grad_f, x0, alpha=0.1, tol=1e-6, max_iter=100) {
  x <- x0
  
  cat("\n──────── MÉTODO DEL DESCENSO DE GRADIENTE (R) ────────\n")
  cat(sprintf("%-6s %-25s %-15s\n", "Iter", "x_n (Vector)", "Norma Grad"))
  cat("──────────────────────────────────────────────────────\n")
  
  for (i in 1:max_iter) {
    # 1. Calcular gradiente (dirección de máximo ascenso)
    grad <- grad_f(x)
    
    # 2. Calcular magnitud del gradiente
    norm_grad <- sqrt(sum(grad^2))
    
    # Mostrar progreso
    x_str <- paste("(", paste(round(x, 5), collapse=", "), ")", sep="")
    cat(sprintf("%-6d %-25s %-15.6e\n", i, x_str, norm_grad))
    
    # 3. Verificar si llegamos al fondo (convergencia)
    if (norm_grad < tol) {
      cat(sprintf("\n✔ Convergió en %d iteraciones.\n", i))
      return(x)
    }
    
    # 4. ACTUALIZACIÓN: Dar un paso en dirección opuesta al gradiente
    x <- x - alpha * grad
  }
  
  cat("\n✘ No convergió.\n")
  return(x)
}

# --- DEFINICIÓN DEL PROBLEMA ---
# Función: f(x,y) = x^2 + y^2  --> Gradiente: [2x, 2y]
mi_gradiente <- function(v) {
  return(c(2*v[1], 2*v[2]))
}

# Ejecución desde el punto (2,2)
resultado <- gradiente_descendente(mi_gradiente, c(2, 2), alpha=0.1)
