Método de Punto Fijo

Algoritmo numérico que encuentra las raíces de una función transformando la ecuación f(x)=0 en la forma equivalente x=g(x).

¿En qué consiste?

Buscamos un valor p tal que g(p) = p. Geométricamente, es la intersección entre la curva y = g(x) y la recta identidad y = x.

Criterio de Convergencia

|g'(x)| < 1

Casos de Estudio

1

Número de Dottie

g(x) = cos(x)

Raíz aprox: 0.739085

2

Exponencial Decrescente

g(x) = e-x

Raíz aprox: 0.567143

metodo_del_punto_fijo.py 
import math

def punto_fijo(g, x0, tol=1e-6, max_iter=100):
    """
    Implementación del Método de Punto Fijo
    g: función despejada x = g(x)
    x0: valor inicial
    """
    print(f"\n{'Iter':<6} {'x_n':<12} {'g(x_n)':<12} {'Error':<12}")
    print("─" * 45)

    for i in range(1, max_iter + 1):
        x1 = g(x0)              # Calculamos siguiente valor
        error = abs(x1 - x0)    # Error relativo
        
        print(f"{i:<6} {x0:<12.6f} {x1:<12.6f} {error:<12.6e}")
        
        if error < tol:
            print(f"\n✔ Convergencia alcanzada: x ≈ {x1:.8f}")
            return x1
            
        x0 = x1
    
    print("\n✘ No convergió en el número máximo de iteraciones")
    return None

# ==========================================
# EJECUCIÓN DE EJEMPLOS
# ==========================================

print("\n--- EJEMPLO 1: g(x) = cos(x) ---")
g1 = lambda x: math.cos(x)
punto_fijo(g1, 0.5)

print("\n--- EJEMPLO 2: g(x) = e^(-x) ---")
g2 = lambda x: math.exp(-x)
punto_fijo(g2, 0.5)
